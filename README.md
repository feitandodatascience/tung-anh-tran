# tung-anh-tran

Source of Tung Anh Tran's public portfolio site.

## Layout

| Path | What it holds |
|---|---|
| `design/tokens.json` | Brand design tokens (colour, type, spacing). The single source of truth for brand values; nothing else hardcodes them. |
| `content/` | Published project and competition pages (added through reviewed pull requests). |

## Brand

"Clay & Olive": espresso ink on a sand ground, one clay-orange signal, olive for links.
Type is Glacial Indifference (SIL OFL 1.1) in Regular and Bold, with General Sans as a
fallback where mid-weights are needed.
